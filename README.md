# Blizzless Runewords

Справочник рунных слов для частного сервера Diablo II Blizzless: на странице собраны **оригинальные и переработанные рунворды**, которые реально используются на сервере — с рунами, типами предметов, уровнем и подсказками по отличиям от классики.

**Опубликованная версия:** [raferty.github.io/blizzless-runewords](https://raferty.github.io/blizzless-runewords/)

---

## Возможности

- компактная таблица и адаптивная сетка в графитовой теме на чёрном фоне;
- отдельный столбец класса в таблице; пунктирные границы панелей и элементов;
- поиск по названию, руне или типу предмета; клавиша `/` переводит фокус в поиск;
- фильтры по основе, сокетам и версии, жёлтые активные фильтры и общий сброс;
- локальный `UiSelect` для основы и сортировки: клавиатура, поиск по первым
  буквам, собственный выпадающий список в теме приложения;
- сортировка по названию, уровню и сокетам; в таблице заголовки названия
  и уровня переключают направление сортировки;
- избранное с сохранением в `localStorage`;
- вкладки баз в сетке и модалке для рецептов с отдельными наборами свойств;
- модалка с порядком рун, копированием рецепта и раскрываемой оригинальной версией;
- открытие подробного описания по всей площади карточки, включая пустое место;
- выбор рун в сайдбаре — подсветка «собранных» рун и полных рецептов;
- русский и английский интерфейс (язык сохраняется в `localStorage`).

В таблице выбор рун сохраняет все результаты и подсвечивает совпадения; полные
рецепты показаны первыми. В сетке остаются рецепты хотя бы с одной выбранной руной.
Выбор базы синхронизирован между карточкой и модалкой, в том числе при смене языка.

Сетка содержит до четырёх колонок на обычном десктопе, пять от 2200 px и шесть
от 2800 px; от 3400 px число колонок подстраивается под ширину с минимумом
карточки 420 px. Карточки одного ряда одинаковы по высоте. На телефоне панель
рун размещается над каталогом; широкая таблица прокручивается горизонтально
внутри своего блока. Увеличенные иконки и названия рун помещаются в 9 колонок
на экранах до 374 px и в 11 колонок на экранах от 375 до 600 px.

Дизайн перенесён 23.10.2026 из [Blizzless Runewords Reforged](https://blizzless-runewords-reforged.dearowlet20.chatgpt.site/).
Каталог данных при переносе сохранён.

**Стек:** Vue 3, TypeScript, Vite, Pinia, SCSS.

## Данные

Каталог содержит 104 уникальных рецепта и сверён 22.10.2026 с [Blizzless Glossary](https://blizzless.info/ru/runewords) и его [публичным API](https://blizzless.info/api/runewords). Для каждого рецепта используется последняя опубликованная версия Blizzless, а при её отсутствии — официальная версия. Бонусы в карточках включают свойства вставленных рун.

Данные хранятся локально в `src/shared/*runewords.ts`. Hustle представлен отдельно для брони и оружия. Каталог включает 51 переработанный, 5 новых и 6 доступных только в RotW рецептов; эти группы могут пересекаться.

## Локальная разработка

### Требования

- Node.js 18+
- npm или yarn

### Установка

```bash
npm install
# или
yarn install
```

### Запуск dev-сервера

```bash
npm run dev
# или
yarn dev
```

В `vite.config.ts` задан `base: "/blizzless-runewords/"`, поэтому удобно открывать приложение по адресу:

`http://localhost:5173/blizzless-runewords/`

### Сборка

```bash
npm run build
# или
yarn build
```

Артефакты — в каталоге `dist/`.

### Предпросмотр production-сборки

```bash
npm run preview
# или
yarn preview
```

### Проверка типов (TypeScript)

```bash
npm run typecheck     # vue-tsc --noEmit
# или
yarn typecheck
```

### Проверка логики каталога

```bash
npm test
```

Проверяет 104 уникальных рецепта, разделение свойств по базам, фильтры, сохранение
избранного, сортировку и поведение выбора рун. Используются существующие Vite/Pinia,
дополнительный тестовый рантайм не требуется.

### Линтинг и форматирование

```bash
npm run lint          # ESLint + Stylelint (порядок CSS/SCSS-свойств)
npm run lint:fix      # ESLint + Stylelint с автоисправлением
npm run stylelint     # только Stylelint
npm run stylelint:fix # сортировка свойств в .vue / .scss / .css
npm run format        # Prettier
npm run format:check  # проверка стиля без записи
```

Конфиги: `eslint.config.cjs` (flat config), `.prettierrc`, `.prettierignore`, `stylelint.config.cjs` ([Recess order](https://github.com/stormwarning/stylelint-config-recess-order) — сортировка свойств без лишних CSS-правил). Для Prettier подключён `eslint-config-prettier`.

## Деплой на GitHub Pages

```bash
npm run deploy
# или
yarn deploy
```

Скрипт собирает проект (`predeploy` → `build`) и публикует `dist/` в ветку `gh-pages`. В настройках репозитория укажите источник Pages: ветка `gh-pages`, корень.

Итоговый URL (при стандартном имени репозитория):

`https://<username>.github.io/blizzless-runewords/`

Если меняется имя репозитория или путь публикации — обновите `base` в `vite.config.ts`.

## Переменные окружения

`VITE_RELEASE_DATE` — дата релиза в формате `YYYY-MM-DD`. Она передаётся в приложение при сборке и отображается справа в шапке, перед переключателем языка, как «Актуально на dd.mm.yyyy» (или `As of` в английском интерфейсе).

```bash
VITE_RELEASE_DATE=2026-10-22 npm run build
```

Если дата не задана, используется дата сборки по московскому времени. Значение фиксируется в собранном приложении. Переменную также можно задать в `.env.local` или `.env.production.local` для соответствующего режима Vite.

Базовый путь задаётся в `vite.config.ts`.

## Структура репозитория

| Путь | Назначение |
|------|------------|
| `src/components/` | UI: таблица, карточки, фильтры, поиск |
| `src/composables/` | композаблы (руны, дебаунс и т.д.) |
| `src/store/` | Pinia: язык, тексты, данные рунвордов |
| `src/types/` | общие TypeScript-типы |
| `src/utils/` | утилиты (массивы, проверка «полного» набора рун) |
| `src/shared/` | константы: руны, типы предметов, данные рунвордов |
