# Компактные фоны деревьев навыков

8 классов · 24 ветки · 240 навыков · 198 связей из текущих данных Blizzless.

Заголовки и счётчики очков отсутствуют. Верхняя плашка пустая под текст интерфейса. Иконки показаны в неактивном состоянии.

- PNG ветки: 720×1160.
- SVG ветки: масштабируемая версия со встроенными изображениями.
- Превью класса: три ветки рядом, 1088×580.
- Координаты иконок и зависимости: manifest.json.

Исходники: локальные skill-tree.jpg, нативные слои wowhead/trees/, иконки wowhead/icons/ и images/skills/. Друид, некромант и Warlock используют те же адаптации, что и планнер.

Воспроизведение SVG: `node scripts/build-compact-skill-backgrounds.mjs`. PNG экспортированы из этих SVG в браузере.

Набор сохранён как отдельные ассеты. Действующее оформление дерева навыков пока не переключено на него.
